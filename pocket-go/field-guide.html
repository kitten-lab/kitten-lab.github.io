03 / Under the surface

A field guide to
your little internet.

The working details: what each cabinet keeps, which tokens you can put on a page, and how files become rooms.

CabinetsLook roomsRoom tokens

A few words before you wander.

Room
A folder you can visit, with notes inside.
Crate
A page’s identity, shared by the cabinets that work with it.
Dress
The CSS that gives a room its appearance.
Token
A mark on a page that displays material or a tool.

Cabinet reference

BIOS is the letter — you edit the WWW from inside it. The others are mouths on the same crate. Each booth is an instruction card: files is what you put in the drawer. look tokens is what you plant on a page so the room can show it. opens is the dressed host that tool lives in.

librarian · ctrl+shift+l

Catalog

Structured facts about this page. Booth green. A different drawer from tags.

files
Add Meta (time, bool, input, textbox). Add Lore. Attach Lore. A ledger by field, not by word.
look tokens
  • {{meta}} Prints this page’s catalog onto the paper, so filed facts are part of the room.
  • {{lib:label}} One field, in place — author, or whatever you named it — without opening the drawer.
  • {{shelf}} A card shelf for this place. The page can wear its own catalog as furniture.
opens
Report sheets, dressed as mypi:lib. Lore cards land in the librarian tray. The catalog does not mint a tag shop — that is Charlie’s job.

charlie · ctrl+shift+c

Weave

Names connecting to names. Amber phosphor. Associative mind, not a record type.

files
from * rel > to. Pins, threads, hashes. A hash on the paper is a view. A pin is something you filed.
look tokens
  • {{tagsearch}} Plants a tag search on any page, so looking up a word does not require a trip to the shop.
  • {{taglook}} What already edged this crate — the weave that is already here.
  • #word A hash printed on the note. Click it and you are on that word across the pocket.
opens
go.tags — Charlie’s Tag Emporium. The shop is clay that calls Charlie’s tag tools: scan a word, on-touch mint, look-through of what already edged that crate. The host is the dressed room those tools live in.

detective · ctrl+shift+a

Hunt

A second mind on the same crate. Stamp red. Case thoughts that never land in the catalog.

files
Own meta bank. Own lore house. Librarian can catalog the same crate and never hold these thoughts.
look tokens
  • {{huntsearch}} A keyword box you can drop on any page. Hunt without leaving the room.
  • {{huntlook}} Hits for the query you are on, printed in the hall.
  • {{meta:detective}} Detective’s chips on this page — the case shelf, visible.
  • {{det:label}} One detective field, in place, the way {{lib:}} is for the catalog.
opens
go.detective — Hunt blotter. Bar word hunt. Keyword search across thought slips. Report sheets as mypi:hunt.

tps · ctrl+shift+t

When

Named dates, as known. A year stays a year. Carbon time-card.

files
Title plus as-known: a year, a month, a day, or an instant. created and referenced are the clocks that count.
look tokens
  • {{meta:tps}} Prints this page’s stamps onto the paper, at the precision you actually had.
  • {{tps:label}} One named when — created, referenced, or a title you typed — in place.
opens
Report sheets as mypi:tps. Narrow by the slices that stamp actually has. It does not pretend a year is midnight in January.

cards · ctrl+shift+d

Deck

Lore faces from every mouth on this crate. Fragments you can hop.

files
A card is still a crate on the back. Face is class, title, line. Edges hop. Pop is a small copy. They are materials, not comments.
look tokens
  • {{loresearch}} Keyword across filed lore cards, plantable on any page.
  • {{lorelook}} The hits for that look, as faces in the room.
  • {{faces}} Prints the body of each note in this hall as a grid you can walk.
  • {{face:crate}} One note, anywhere in the pocket, by crate id — printed here.
  • {{edges}} Crates this card touches, as doors. The card is the edge.
opens
go.trays — Lore Memory Decks. One tray per mouth. Bar words lore / cards. The Cards cabinet is the deck on this page; the trays host is where those faces live as rooms.

cites · clay, not a sixth mouth

Addresses

A mark on any page that mints a chain of rooms you can stand on.

files
^crate.XXXX hops a crate. ^OT-008.T01.B002.L03 is one chip-code chain — group, log, trunk, branch, leaf.
look tokens
  • {{codesearch}} Search or mint a chip-code from any page, not only the directory.
  • {{codelook}} Notes that already pointed at this chain — the look-through.
  • {{compost}} The cut that sits on this ZIP: headline, note, tags. The mountain has an address.
opens
go.codes — Chester’s Crates. Using a cite mints the bins. Look-through lists what already pointed here. Compost sits on the node; it does not mint extra pages. Same pattern as Charlie: the directory exists because the code tools were planted there.

Clay & room tokens

Tokens on any page. The token decides what is listed. The environment decides how it looks. Cabinets are drawers. These are the holes they plant so a room can contain anything.

{{paper}}
The hole in a dress shell. Filled with the note you opened.
{{subshell}}
Nested chrome that sits in the parent’s paper hole. A hall inside a campus.
{{files}}
Notes in this folder. A bookstore paints them as covers; another skin can make a list.
{{doors}}
Subfolders as door cards. A host becomes a street of rooms.
{{dir}}
Notes and subfolders together. The hall as a directory.
{{tree}}
A file tree from the dress shell. Folders open and close. The path you are on stays open.
{{faces}}
The body of each note in this hall, printed as a grid you can click into.
{{cover}}
This page’s jacket, printed where you put it. The environment dresses the object.
{{crumb}}
The trail: home / folder / note. You can always walk back.
{{recent}}
Last kept notes across the pocket. Type recent on the bar.
[[Note]]
Wiki to a file or a room of that name, inside the host you are standing in.

A folder in ~hosts/ is a WWW. A folder becomes go.{name}. The page is the crate. The file still opens in any editor.

Other pocket products, not this one: Pocket Notebook is cloth books. Pocket Chapbook is a poem pool. Go is the WWW.
