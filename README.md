# Kitten Lab

Public site for [Danielle Leve](https://kitten-lab.github.io/) — products, games, and tools from Kitten Lab (est. 2026).

Static HTML. GitHub Pages from `main`. Edit any page by opening the file — `index.html` is the homepage, `work/*.html` are the product pages. Pocket Go has its own section in `pocket-go/`: Home, Rooms, Cabinets, and a Field Guide. Those pages share `css/home.css` and `css/pocket-go.css`; keep their section navigation consistent when adding a page. The former `work/pocket-go.html` address forwards visitors to the new section. Change the words. Save. Push `main` when you want it live.

The org notebook [`kitten-lab/kitten-lab`](https://github.com/kitten-lab/kitten-lab) is a separate repo. Do not merge this site into it.
