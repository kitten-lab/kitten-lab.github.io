Tool

Deck Host

Active Windows for small software

Why

Browser tabs dissolve. I wanted the lab’s small programs to feel like things you open: a dedicated window, a path to ship one tool as one install. Deck Host is that coat. The product inside stays itself.

It is infrastructure with a point of view. If we store more than we can hold, the containers still have to be findable with the hands.
