Game

Terminal Prolog

Public spec Thought, not action

Why

Most parser games are inventories with a story attached. I wanted the opposite: no verbs of action. You think. You remember. You try to bootstrap cognition without knowing who or what you are.

It is the lab in miniature. If a self is something we reconstruct, can a player do it with language alone?

Status

Public on GitHub as a parser-based game exploring cognition. Still a piece I return to. Not a fake-finished store page.
