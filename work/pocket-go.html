Pocket Go

close to ship a WWW you inhabit

Markdown as rooms. BIOS as a tiny IDE. Cabinets that follow the page — and plant the tokens that make a look-through exist. The dress can look like a fever dream. The machine is not.

desk features bios cabinets look rooms

the desk

Four parts, one pocket. You type a bar, enter a room, file a mouth, edit the clay without leaving.

bar

go.{host}/path. Nicknames: tags codes hunt recent start. Back, forward, home, refresh.

rooms

A folder in ~hosts/ is a WWW. _shell.md is chrome. index.md is paper. The page is a crate.

BIOS

Docked IDE. Room letter, shell, paper, CSS. Keep. Mint a page, a folder, a shell, a host. Help rides with you.

cabinets

Five mouths on the crate you are standing on. Empty on the lobby because the lobby is not filed. Walk into a room.

features

Clay on any page. Tokens decide what is listed. The environment decides how it looks. Cabinets are not these — they are drawers.

hosts

A folder becomes go.{name} as soon as it exists. Skins live in mats/styles/. Wiki, tags, and slots stay inside the host you are standing in.

shell and paper

{{paper}} is the hole in a dress shell. {{subshell}} nests a hall in the parent hole and still gets its own crate.

lists and holes

wiki

[[Note]] to a file or a room. Resolves inside this host. Not a global search.

crates

The page is the id. Hop by crate, not by a path that will move. Click a crate in any drawer for the full cabinet report.

why markdown like this

The file still opens in any editor. The pocket is how it wears a place, a crate, and a set of mouths — without becoming a database you cannot hold.

BIOS

A tiny IDE docked on the desk. The pocket is not a viewer with a secret repo behind it. You change the WWW from inside the WWW.

cabinets

Each mouth is a different kind of truth about the same crate. Each mouth also has look tokens — clay that prints a search, a look-through, a shop. The room those tokens open is not a separate product. Charlie does not “have” a tag site. Charlie calls tag tools, so go.tags exists.
