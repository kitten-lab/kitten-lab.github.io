Pocket Notebook

close to ship cloth books

Pocket Go ate the word pocket. This is a different product: a shelf of cloth notebooks. Open a book, scrub pages, edit the source, the view prints. Work-brain. Field notes. Lore books. Not a terminal. Not a chapbook. Not a little WWW.

shelf book edit packs not the others

the shelf

Last opened as covers. Library as spines you can drag. Cloth is oxblood, forest, navy, sand — a named cover, not a theme on one notes app. Whisper is the face title.

covers

The books you were just in. Click opens. Pencil names cloth and whisper.

spines

The whole library on a rail. Drag to arrange. + NEW mints a book.

place

Each book remembers its page and scroll. Shelf does not forget the pile.

cold start

If you left mid-book, it reopens that book. Esc / ← SHELF is the desk.

an open book

Printed page, not a file tree. Contents on the left. A scrubber along the bottom. A ribbon on the edge if you marked the leaf.

TOC

T toggles. ↑ / ↓ reorder leaves. Dots show marks. The row is the page.

flip

← → or the arrows. The slider is a page count, not a scroll of maybe.

bookmark

B cycles. Hover swatches: hot, brass, forest, navy, sand. Ribbon on the page. Dots in the TOC.

N / − PAGE

New page. Remove this one (not the last). Confirm. The book stays a book.

edit, then print

E, or double-click. Type markdown. Ctrl+S. The page is the printed face. Not always-raw. That felt like VS Code.

packs

Each notebook is a .bok on disk. Operator data lives in safe_box, not inside the system code. Same house law as the other boxes.

book.md

The notebook’s name, whisper, cloth. The cover is data.

pages/

One markdown file per leaf. Human packs. You can still open them in any editor.

shelf.json

Last-opened ids. Not the books. The desk’s memory of the rail.
