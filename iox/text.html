Model behavior observations

Patterns I logged from daily work with AI coding assistants on unconventional architecture, and what I changed in response.

  • Context rot. A sprawling, contradictory working environment degraded the agents’ work. I scoped my dev agent to the codebase only, with no access to documentation, had it migrate and rename old pieces so the work became its own, and moved to individuated agents that each return to one narrow lane.
  • Scattered metadata. Agents made too many jumps across metadata stored in separate folders and missed data. I built RoseDoc, a bundle format that keeps metadata with the document.
  • Spec drift and handoff loss. Stated architectural principles were quietly overwritten despite long upfront context: composable pieces collapsed into one hard-styled object, deliberate unconventional code was read as error, and meaning dropped between the conversational model and the one executing the work. I treat the spec as the carrier of intent, written for a team that doesn’t ask questions, and keep each agent close to the code it owns.
  • Stale memory over live instruction. Agents trusted an old README over my direct instruction and wrote memory notes of in-the-moment inference that compounded. Glass Compost tracks order so newer beliefs supersede older ones, and I’m working on data organization for cleaner long-term recall and for tracking how decisions change over time.
